# Shop Cart Structure

This project is a React + Vite scaffold for a shopping cart UI.

The app currently includes structure only:

- App.jsx
- ProductList.jsx
- ProductCard.jsx
- Cart.jsx
- CartItem.jsx

Cart state, add-to-cart behavior, totals, and remove actions are intentionally not implemented yet.

## Run the project

```bash
npm install
npm run dev
```
